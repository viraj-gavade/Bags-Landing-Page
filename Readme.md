# Bags Landing Page

A responsive landing page showcasing a collection of bags, built with HTML, CSS, and JavaScript. The page is designed to provide an engaging user experience on both desktop and mobile devices.

## Live Demo

Explore the live demo here:

[Live Demo](https://bags-landing.netlify.app/)

## Technologies Used

- HTML
- CSS
- JavaScript

## Installation

To run the project locally:

1. Clone the repository:
    ```bash
    git clone https://github.com/viraj-gavade/Bags-Landing-Page.git
    ```

2. Navigate to the project folder:
    ```bash
    cd Bags-Landing-Page
    ```

3. Open `index.html` in your browser.
